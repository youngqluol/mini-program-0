## 注销账号（M5-10）—— 提审最后一项硬性要求 ✅

**用户决策**：`.workbuddy/` 不加进 `.gitignore`（明确指示）。

### 数据口径（写死在 `server/src/modules/auth/account.service.ts` 文件头）

一句话：**「认人的抹掉，家里的事留下但不再署名」**

| 数据 | 处理 |
| --- | --- |
| `users` | 匿名化 + `status=0` + **openid → `deleted:<id>` 墓碑值** |
| `family_members` | **保留行**，`status=0`（只对 ACTIVE 写 `leftAt`）+ `role_name` → 「已注销的家人」 |
| `thing_reminders`（发给他的、未发出的） | `status=3` + `next_remind_at=null` |
| `notification_logs`（发给他的） | **物理删除** —— 全库唯一例外 |
| `family_things` / `memories` / `meal_records` / `menu_items` / `invites` | 原样不动 |
| `families`（他是创建者的） | 交接给**最早加入**的其他成员；没有别人则 `status=0` 解散 |

**墓碑值用 `:` 的数学理由**：微信 openid 字符集 `[A-Za-z0-9_-]`，冒号不可能出现 → 与真实 openid 不会撞车，不需要去重逻辑。语义收益：同一微信再登录是**全新空账号**（`upsertUser` 按 openid 找不到旧行）。

### 踩到并修掉的两个真问题（这是本轮最有价值的部分）

1. **`ThingService.userIdOfMember()` 不看成员状态** —— 光把成员置 `status=0`，
   调度器到点**照样会继续叮他**（`fireDueReminder` 只反查 `user_id`）。
   必须在注销事务里**显式取消**未发出的提醒。
2. **`JwtGuard` 原本只验签、不查账号状态** —— 于是「注销」退化成「前端清了一下本地缓存」，
   旧 token 能一直用到 7 天后过期。已加 `assertUserActive()`：
   验签后查一次 `users.status`，非 ENABLED → `40100`（**刻意不用 40301**：
   40100 触发静默重登 → 墓碑 openid 命中不了 → 新建空账号 → 落到引导页，
   这是「已注销」该有的收场；40301 会让人卡在报错页面）。

其他设计要点：
- **创建者注销 = 交接，不是拒绝**。V0.1 没做「转让创建者」，但注销是法定权利，
  `FamiliesService.leave()` 那套「你是创建者先转给别人」**不能沿用**。
- **`notification_logs` 是全库唯一物理删除**，已写进 AGENTS.md §4.4 作为显式例外
  （否则下一个 agent 会把它当漏改「修正」掉）。
- 幂等只挡**并发**：第二次带同一 token 打进来时 `JwtGuard` 已经返回 40100，
  根本到不了 service。「响应丢了」那条路由客户端收场（40100 → 静默重登 → 重放）。

### 新增 `tools/pack-deploy.mjs`（`pnpm run pack:deploy`）

零依赖 ZIP 打包器（手写容器格式 + zlib deflate + CRC32，固定时间戳→确定性输出）。

两边天然一致。自带两条断言：① Dockerfile 每个 COPY 源在包内；② 压缩后 ≤ 2 MiB，超了直接退出。

实测产出：**118 文件 / 0.74 MiB 原始 / 0.31 MiB 压缩**。用 Python `zipfile` 独立验证过
（CRC 全好、必备文件齐、无 node_modules/dist/.env 混入），并解压确认是可用的构建上下文。

## 22:55 docs/06 v0.2.10：数据库 / Redis 的三条实情

用户问「后端上云托管，数据库 / Redis 怎么办」，查证后补进 §五：
- **云托管内置 MySQL**（控制台 → 数据库），但不**内置 Redis**。

  **授权绑定 VPC**，再把服务设进该 VPC。原 5.11 只写「打通内网」，漏了这两步。
- MySQL 建完要**建子账号**（root 不允许远程连接），子账号填进 `DATABASE_URL`。
- 新增 5.16：Redis 连不上**不拦启动**（`redis.service.ts` 只 warn 降级），
