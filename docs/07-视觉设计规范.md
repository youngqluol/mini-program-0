## 一、设计基调

参考图来自一个育儿类 App。**我们只借用它的视觉语言，不借用它的功能与人群定位。**

| 参考图有的 | 我们继承 | 我们不要 |
| --- | --- | --- |
| 粉桃渐变主色 | ✅ 全套色彩体系 | — |
| 大圆角 + 柔阴影白卡 | ✅ 卡片规范 | — |
| 柔粉统计卡 / 粉色小圆点标记 | ✅ 组件规范 | — |
| 渐变胶囊按钮 | ✅ 按钮规范 | — |
| 柔和 squircle 图标块 | ✅ 图标规范 | — |
| 卡片角落软萌插画 | ✅ 插画规范 | — |
| 母婴类目功能（喂奶/尿布/疫苗） | — | ❌ 与家庭协作无关 |
| 粉得过于「母婴」的甜腻感 | — | ❌ 下调饱和度，往珊瑚/蜜桃偏 |

**一句话：柔光粉彩的质感，家庭协作的内容。**

### 关键词

```text
柔和 · 圆润 · 留白 · 轻盈 · 温暖 · 不甜腻
```

## 三、圆角与阴影

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-lg` | `20px` | 大卡片、Hero 卡 |
| `--radius-md` | `14px` | 列表项、输入框、小卡片 |
| `--radius-sm` | `10px` | 标签、小色块 |
| `--radius-tile` | `18px` | squircle 图标块 |
| `--radius-pill` | `999px` | 按钮、胶囊标签、分段控件 |

```css
--shadow-card:  0 4px 18px rgba(255, 150, 170, 0.10);   /* 常规卡片，几乎看不见的粉晕 */
--shadow-float: 0 8px 24px rgba(255, 150, 170, 0.22);   /* 主按钮、悬浮按钮 */
```

> **关键：阴影必须是带粉调的，不能用灰色阴影。** 灰色阴影会让粉色体系显脏。这是参考图里最容易被忽略、但最影响质感的一个细节。

## 四、字体与字号

沿用系统字体，不引入自定义字体（小程序包体积敏感）。

```css
font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 令牌 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--fs-display` | 34px | 700 | 大数字（如疫苗倒数 497 天那种） |
| `--fs-h1` | 26px | 700 | 页面主标题（家庭成员 / 育娃手记） |
| `--fs-h2` | 17px | 600 | 区块标题（● 邀请家人） |
| `--fs-h3` | 15px | 600 | 卡片标题、列表主文案 |
| `--fs-body` | 14px | 400 | 正文 |
| `--fs-cap` | 12px | 400 | 辅助说明、时间 |

**字重只用 400 / 600 / 700 三档**，不用 500（小程序端渲染不稳）。

## 五、间距与单位

### 5.1 间距

基础单位 4px，常用组合：

| 场景 | 值 |
| --- | --- |
| 页面左右边距 | 16px |
| 卡片内边距 | 16px（小卡）/ 20px（大卡） |
| 卡片之间 | 14px |
| 区块之间 | 20px |
| 区块标题 → 内容 | 12px |
| 图标块 → 文字 | 8px |

**整体比常规设计更宽松。** 参考图的核心观感之一就是「留白多到有点浪费」——这是柔光粉彩风格成立的前提，挤了就不柔了。

### 5.2 单位选择：为什么用 `px` 而不是 `rpx` ⭐

**结论：本项目统一用 `px`，不用 `rpx`。**

先破除一个常见误解：**「小程序必须用 rpx」是社区习惯，不是微信官方要求。**
微信官方 WXSS 文档现在的原话是：

> 由于历史原因，WXSS 也支持一个类似的长度单位 `rpx`……不过，`rpx` 的计算规则有时会对转换后的数值进行取整，
> 从而带来一些精度问题……此外，由于现在 CSS 标准的 `vw` 单位已经得到广泛支持，所以还是优先推荐使用 `vw`。
>
> **注意：考虑到对手机、PC 等大屏幕设备的支持，不建议滥用 `vw` `rpx` 等基于屏幕宽度比例的单位。**

即：官方优先推荐 `vw`，并明确**不要滥用基于屏幕宽度比例的单位**（`rpx` 正属于这一类）。

#### 本项目选 px 的四个理由

| 理由 | 说明 |
| --- | --- |
| **要跑在大屏上** | 小程序不只在手机跑，还有 **iPad** 和 **微信 PC 端**。`750rpx` 恒等于屏幕宽度 —— 在 iPad 上所有元素被等比放大到失控（32rpx 的间距会变成 40+px） |
| **物理尺寸一致更重要** | 家庭工具，阿妈在 375pt 手机上看到的按钮，换到 430pt 手机上不该变大 15%。`px` 保证「换设备，大小不变」 |
| **设计基调是留白** | 观感来自「留白多到有点浪费」。`px` 在大屏上只会更空，不会挤破；`rpx` 反而会把留白放大成空洞 |
| **避开 rpx 取整误差** | 官方点名的精度问题，在圆角 / 边框这类小数值上容易出 1px 缝 |

#### 代价与对策

`px` 的代价是：**屏幕越宽，内容占的比例越小**（大屏上内容会显得窄）。
对策是给内容设**最大宽度并居中**，而不是让元素跟着屏幕拉伸：

```css
/* app.wxss —— 已实现 */
.page {
  max-width: 480px;   /* 超过它的设备（iPad / PC）按 480 居中 */
  margin: 0 auto;
}
```

> 480px > 最大手机宽度（iPhone Pro Max 约 430pt），所以**手机端完全不受影响**。

#### 什么时候才该用 rpx / vw

只有一种情况：**需要严格按屏幕比例缩放的装饰性元素**（铺满宽度的插画、全宽渐变背景）。
这类元素**优先用 `vw`**（官方首选），不要用 `rpx`。

## 六、组件规范

### 6.1 按钮

**主按钮（渐变胶囊）**

```text
高度 48px · 圆角 999px · 背景 var(--brand-grad)
文字 白色 · 15px · 600 · 字距 1px
阴影 var(--shadow-float)
按下态：透明度 0.85 + scale(0.98)
```

**次级按钮（浅粉底）**

```text
高度 44px · 圆角 999px · 背景 var(--brand-soft)
文字 var(--brand-ink) · 14px · 600
无阴影
```

**文字按钮**：`var(--brand-ink)` 14px，无底色，用于「重新生成」「更多 →」。

### 6.2 输入框

```text
背景 var(--surface-2)  #F8F2F9  ← 注意是带紫调的浅底，不是灰色
圆角 var(--radius-md) 14px
内边距 14px 16px
无边框（这是关键：参考图的输入框完全没有描边）
占位符 var(--ink-3)
聚焦态：背景变 #FFF，加 1px var(--brand-1) 描边 + 淡粉外发光
```

### 6.3 卡片

**标准白卡**

```text
背景 #FFF · 圆角 20px · 内边距 16-20px
阴影 var(--shadow-card)
```

**柔粉卡（用于统计 / 强调）**

```text
背景 var(--brand-soft) #FFEEF2 · 圆角 14px · 内边距 14px
无阴影
结构：大数字（var(--brand-ink), 24px, 700）+ 标签（var(--ink-3), 11px）
```

参考图里「今日总结」的三个卡片（0次 / 0ml / —）就是这个组件。

### 6.4 区块标题

参考图最有辨识度的元素：

```text
● 邀请家人

结构：粉色小竖条（3px × 14px，圆角，var(--brand-ink)）+ 8px 间距 + 标题
标题 17px / 600 / var(--ink-1)
右侧可选：「更多 →」 文字按钮
```

> 用**小竖条**而不是 emoji 或图标，保持克制。

### 6.5 squircle 图标块

```text
尺寸 52px × 52px · 圆角 18px
背景：对应模块的 pastel 色
内容：emoji 或线性图标，24px
下方标签：12px / var(--ink-2)，居中，间距 8px
```

参考图「快速记录」的九宫格就是这个组件。我们用在家首页的模块入口。

### 6.6 分段控件

```text
外容器：白色 · 圆角 999px · 内边距 4px · 1px var(--line) 描边
选项：14px · var(--ink-2) · 圆角 999px · 内边距 8px 0
激活项：背景 var(--brand-grad) · 白色文字 · 600
```

参考图「7天 / 14天 / 30天」就是这个。

### 6.7 列表项

```text

结构：[左侧图标块/时间] [主文案 15px] [右侧称谓/状态 12px var(--ink-3)]

```

### 6.8 胶囊标签

```text
小标签：背景 var(--brand-soft) · 文字 var(--brand-ink) · 11px · 圆角 6px · 内边距 3px 8px
```

### 6.9 空状态

```text
居中 · 上下留白 32px
插画/emoji 40px
```

## 七、插画规范

参考图里每张卡片角落都有一张软萌插画（家庭、盾牌、宝宝），这是风格的重要组成。

| 项 | 规范 |
| --- | --- |
| 风格 | 扁平矢量，无描边，圆润几何形 |
| 色彩 | 从粉彩色板取色，最多 4 色 |
| 位置 | 卡片右上角或右下角，部分出血 |
| 尺寸 | 卡片高度的 60%–80% |
| 内容 | 房子、家人、心形、小物件 |
| 禁止 | 写实风、3D 渲染、复杂渐变、人物五官细节 |

**实现方式：** 优先用内联 SVG（体积小、可换色、清晰）；复杂插画用 PNG 放 `assets/illustrations/`。

## 十、中转页视觉规范（推送落地页）

> **这一章是 v0.2.1 新增。** 用户从微信服务通知点进来，落到的**不是小程序**，而是一张网页（Worker 的 `/skin`）。
> 它是用户对「家有小事」的**第一印象之一**，视觉必须与小程序一致，不能是另一个产品的样子。

### 10.1 为什么必须重做

上游 wxpush 自带的中转页是**深蓝科幻风**（`linear-gradient(135deg, #0c0c2e, #1a1a3e)` + 霓虹色），
与「柔光粉彩」完全冲突。用户从一条温馨的家庭提醒点进来，看到的是赛博朋克页面——**品牌感直接断裂**。

### 10.2 页面结构

```text
┌─────────────────────────────┐
│                             │  ← 背景 #FDF6F7
│   ┌─────────────────────┐   │
│   │  🔔                 │   │  ← squircle 图标块 52px
│   │                     │   │     底色 #FFE4EA（叮一下粉）
│   │  阿妈，有个活儿到你啦～ │   │  ← first，17px/600/#1F1F1F
│   │  ─────────────      │   │  ← 分割线 #F5EDEF
│   │  事项：记得买酱油      │   │  ← keyword1，14px/#6B6B70
│   │  来自：阿爸           │   │  ← keyword2
│   │                     │   │
│   │  有空的时候弄一下就行😊 │   │  ← remark，14px/#9B9B9B
│   │                     │   │
│   │  2026-10-06 20:15   │   │  ← 时间，12px/#9B9B9B
│   └─────────────────────┘   │  ← 白卡 20px 圆角 + 粉调阴影
│                             │
│   ┌─────────────────────┐   │
│   │    [小程序码图片]     │   │  ← 长按识别
│   │                     │   │
```

| --- | --- |
| 页面背景 | `#FDF6F7` |
| 卡片 | `#FFFFFF` · 圆角 `20px` · 阴影 `0 4px 18px rgba(255,150,170,.10)` |
| 标题（first） | `17px / 600 / #1F1F1F` |

| --- | --- | --- |

| 系统 | 💬 | `#E3F0FB` |

### 10.4 硬性要求

- [ ] 背景 `#FDF6F7`，**不是深色**
- [ ] 卡片圆角 20px + **粉调阴影**，不是灰阴影
- [ ] 小程序码区块**必须可长按识别**（`<img>` 不能加 `pointer-events: none`）
- [ ] 页面上不出现「测试号」「公众号」「关注」「绑定」等字眼
- [ ] 移动端优先（`max-width: 420px` 居中，`viewport` 已设）
- [ ] 无 JS 依赖也能正常展示（纯静态 HTML，消息内容从 query 参数读）

> **实现位置：** `wxpush/index.js` 的 `/skin` 路由。

## 十二、设计自查清单

新页面开发完成后自查：

- [ ] 背景是 `#FDF6F7` 而不是纯白或纯灰？
- [ ] 阴影是粉调而不是灰调？
- [ ] 输入框无描边、用 `#F8F2F9` 底？
- [ ] 区块标题用了粉色小竖条而不是 emoji？
- [ ] 尺寸单位用的是 `px` 而不是 `rpx`？（见 §5.2）
- [ ] emoji 是否装在粉彩 squircle 块里？
- [ ] 留白是否足够宽松（页边距 16px、卡间距 14px）？
- [ ] 模块颜色是否用对了（叮一下粉 / 派活蜜桃 / 吃啥呢鹅黄 / 留个念藕紫）？
- [ ] 主按钮是不是渐变胶囊、有没有柔和发光？
- [ ] 有没有出现灰色阴影、纯色描边、直角、深色块？**出现即返工。**
