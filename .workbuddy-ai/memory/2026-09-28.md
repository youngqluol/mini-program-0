## 《家有小事》开发前准备工作完成

### 背景
项目「家有小事」——面向家庭成员的事务协作微信小程序。已有 3 份 v0.1 文档（产品需求 / 核心数据模型 / MySQL 数据库设计），本次补齐全部开发前准备。

### 关键技术决策（重要）
- **小程序端**：原生微信小程序 + TypeScript（不用 uni-app/Taro）
- **后端**：微信云托管容器 + NestJS + Prisma
- **数据库**：云托管 MySQL 8.0 —— 保留已有 11 张关系表设计
- **关键澄清**：云开发自带的「云数据库」是文档型（类 MongoDB），与关系模型冲突，故云开发**只用于云存储等能力**，业务数据走 MySQL
- **部署**：微信云托管（默认域名免 ICP 备案）
- **鉴权**：wx.login → code2Session → 自签 JWT（7天），session_key 存 Redis 不落库

### ⚠️ 重大风险（已记录在 01 文档第五章）
微信**长期订阅消息仅对政务民生/医疗/交通/金融/教育等特定行业开放**，「家有小事」属家庭工具拿不到资质，只能用**一次性订阅**（授权一次只能下发一条）。
应对：① 在所有自然交互点累积授权额度（Redis 计数）② 额度耗尽时降级到站内消息中心 ③ 首页「今日小事」承担主要提醒职责。3 个订阅模板需提前申请（审核 1-3 天）。

## 下午追加：视觉风格重塑 v1.0「柔光粉彩」

### 触发
用户提供 `ui/风格参考/` 下 3 张图（育儿类 App），要求**只参考样式、不参考功能与人群**。

### 参考图提取的视觉语言
- 粉桃渐变主色、极浅粉白背景、白色悬浮卡片
- 大圆角 + 极柔阴影（**阴影必须带粉调，用灰阴影会让粉色显脏**）
- 柔粉统计卡（大数字 + 小标签）
- 粉色小圆点/小竖条做 section 标记
- 渐变胶囊主按钮 + 浅粉次级按钮
- 粉彩 squircle 图标块（52px / 圆角 18px）
- 浅紫粉底无描边输入框
- 卡片角落软萌扁平插画

### 落地决策
- 主色定为 `#FF9DB4 → #FFB59B` 渐变 —— 终点用**蜜桃而非纯粉**，避免家庭工具显得像母婴 App，同时延续原有暖橙血脉
- 四大模块分配固定粉彩色，形成记忆点
- 保留全部产品纪律与文案规范不变
