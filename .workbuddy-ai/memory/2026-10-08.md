### 1. 修掉一个部署级缺陷：`.dockerignore` 放错位置 ⚠️

**根因**：`docs/04` §一 的目录树把 `.dockerignore` 画在 `server/` 下，实现照着做了。
但 `server/Dockerfile` 的 COPY 源包含 `package.json` / `pnpm-workspace.yaml` /
`packages/shared` —— 说明**构建上下文是仓库根**，而 Docker 只读**上下文根**的忽略文件。
`server/.dockerignore` **从不生效，也不报任何错**。

**后果**（不是「多拷几个文件」这么轻）：

```
本机是 Windows → server/node_modules 里是 Windows 版 Prisma query engine
  → COPY server ./server 把宿主机那份盖掉容器里刚装好的 Linux 版
  → 容器启动即报「找不到当前平台的 query engine」
```

这类错误**只在云端构建时才暴露**，本地怎么跑都复现不出来。

**修复**：`.dockerignore` 移到仓库根、删掉 `server/.dockerignore`（死文件）、
新增 `tools/check-docker.mjs`（校验同阶段 COPY 源未被忽略规则误伤 + 断言
`.dockerignore` 的位置与关键规则），挂进 `pnpm run check`。
**三种破坏方式都反向验证过**（缺关键规则 / 位置放错 / COPY 源被排除，都能拦住）。

### 3. M5-5 隐私协议弹窗 ✅

核实官方文档后定口径：**P01 首次进入主动提示 + 微信官方弹窗兜底**，
**不接管** `onNeedPrivacyAuthorization`。

- 2023-10-17 之后 `__usePrivacyCheck__` 配不配都会启用 → **不配**
- 官方弹窗只在**用户真正触发隐私接口**时才弹 → 首次进入仍需自己提示一次
- 本项目只用 `wx.chooseMedia`（相册）一个隐私接口；不用地理位置
  → **不需要 `requiredPrivateInfos`**（那是地理位置类接口专用的）
- 文案用「**同意**」不用「授权」（后者是 AGENTS.md §6 的界面禁用词）
- 检查放在 `guardEntry()` **之后**（避免异步回调 setData 到已卸载页面）
- 「本次启动只提示一次」用**模块级标记**，不用 `data`（data 会随页面卸载重置）

### 4. `BASE_URL` 按小程序版本自动切换

`wx.getAccountInfoSync().miniProgram.envVersion`：
`develop` → 本地、`trial` / `release` → 云托管域名。
`PROD_BASE_URL` 是显式占位符。防「本地真机调试改成局域网 IP、发版前忘了改回来」。
